# Creavent

## Description

Creavent is a web platform that brings vendor-based community events together in one place. Organizers plan and promote their events, vendors find events and secure spots, and attendees discover where to go and who will be there.

## Scope

- **Initial focus:** flea markets and flea market organizers. The MVP and early development are built around them.
- **Future direction:** other vendor-based events such as bazaars, pop-ups, and similar gatherings.
- **Not in scope for now:** ticketed or paid entry for attendees.

The platform is described in general terms (events, organizers, vendors, attendees) so it can grow beyond flea markets later.

## Roles and Features

### Organizer

Plans, promotes, and runs events.

- Create a verified organizer account
- Create and manage events (name, date, location, details)
- Promote events through a public event page
- Open vendor applications and recruit vendors
- Set vendor requirements (product categories, limits on similar vendors, required permits)
- Review, approve, or decline vendor applications
- Set slot pricing and reservation fees
- Create an event floor plan
  - Place and arrange slots
  - Assign slots to vendors
  - Draw walkways and paths
  - Mark other areas (entrance, exit, stage, food area, etc.)
- Publish the floor plan to the public event page
- Message vendors
- Send and manage vendor contracts/agreements
- Track reservation payments and payouts
- View the vendor list and slot availability at a glance
- Post event updates and announcements

### Vendor

Finds events to join and manages participation.

- Create a verified vendor account (e.g., ID or business permit)
- Create and manage a vendor profile (shop name, products, photos)
- Browse and search for upcoming events
- Apply to join an event
- Submit required permits or documents for an event
- View the event floor plan and available slots
- Choose or request a preferred slot
- Message event organizers
- Review and sign contracts/agreements
- Pay slot reservation fees through the platform
- View the status of applications and reservations
- Track upcoming events joined
- Receive event updates and announcements

### Attendee

Discovers events and plans visits.

- Browse upcoming events by date and location
- View event details (schedule, location, description)
- See which vendors are joining each event
- View vendor profiles and what they sell
- View the event floor plan and find where vendors are located
- Identify verified organizers and vendors
- Save or follow events of interest
- See event updates and announcements
